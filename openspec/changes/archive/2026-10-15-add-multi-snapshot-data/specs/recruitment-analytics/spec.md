# Spec Delta

## MODIFIED Requirements

### Requirement: 筛选条件语义
系统 SHALL 支持按快照期次、城市、经验、学历四个维度筛选岗位数据；多个条件同时给出时取交集；未给出的维度视为不限制，其中期次未指定时 MUST 默认取最新一期，统计 MUST NOT 混合多个快照的数据。筛选结果 MUST 一致地作用于该页全部指标与图表（技能页的数据边界见"技能数据的来源与筛选边界"）。

#### Scenario: 单条件筛选
- **WHEN** 筛选条件为 城市=杭州
- **THEN** 所有指标只统计当前期次（未指定期次时为最新期）的杭州岗位

#### Scenario: 多条件交集
- **WHEN** 筛选条件为 城市=杭州 且 学历=本科
- **THEN** 只统计同时满足两个条件的岗位

#### Scenario: 期次筛选
- **WHEN** 筛选条件为期次=2018
- **THEN** 所有指标只统计 2018 期快照的岗位

#### Scenario: 不限制
- **WHEN** 未提供任何筛选条件
- **THEN** 统计最新一期快照的全量数据，不与其他期混合

### Requirement: 技能数据的来源与筛选边界
技能类统计（词频、共现）MUST 来源于岗位技能表（已提取的技能词），不参与城市 / 经验 / 学历筛选，但 MUST 按当前期次隔离统计——技能记录的岗位标识仅在同一快照内唯一，跨快照 MUST NOT 把不同期的技能记到同一岗位名下；技能页始终展示当前期次的全量技能统计，并在页面注明该限制；当前期次无技能数据时技能统计结果为空，MUST NOT 回退到其他期次的数据。

#### Scenario: 技能页不受筛选影响
- **WHEN** 在技能页选择 城市=北京
- **THEN** 技能图表仍基于当前期次的全量技能数据，页面注明技能数据不支持该维度筛选

#### Scenario: 跨期隔离
- **WHEN** 两个快照的技能记录中存在相同的岗位标识，两个快照中各有 1 个含 python 的岗位
- **THEN** 各期 python 的词频均为 1，不因岗位标识相同而合并或累计

#### Scenario: 无技能数据的期次
- **WHEN** 当前期次不包含任何技能记录
- **THEN** 技能统计返回空结果，不回退使用其他期次的技能数据
