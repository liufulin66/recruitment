## 1. 环境准备

- [ ] 1.1 初始化 git 仓库并完成首次提交（`.gitignore` 排除 `.venv`）；验证：`git log` 有首次提交、`.venv` 未被跟踪
- [ ] 1.2 安装并启动 MySQL 服务（或确认可用实例），创建 `recruitment` 库与账号（utf8mb4）；验证：用客户端连接后 `SHOW DATABASES` 可见该库
- [ ] 1.3 逐个讲解 pandas / Flask / PyMySQL / jieba / pyecharts 后（逐一确认）安装进 `.venv`，生成 `requirements.txt`；验证：`pip install -r requirements.txt` 成功、五个包可正常 import
- [ ] 1.4 将 PyCharm 模块解释器从 LibreOffice Python 切换到 `.venv`；验证：IDE 右下角显示 `.venv`，脚本以该解释器运行

## 2. 数据集准备

- [ ] 2.1 从候选池选定数据集放入 `data/`，核对必填字段（职位名/公司/薪资/城市/学历/经验/技能文本）并尽量覆盖公司规模、行业；验证：字段核对清单 + 数据抽样预览
- [ ] 2.2 抽取真实样例值（薪资形态、城市写法、学历/经验取值），形成解析与归一的用例输入表；验证：样例表覆盖 specs 中出现的各类形态

## 3. 清洗核心：薪资解析与枚举归一

- [ ] 3.1 编写薪资解析用例表（K 区间 / 千 / 万 / 年薪 / 13薪 / 面议，含 2.2 的样例值）；验证：用例文件覆盖 `data-pipeline` 全部薪资场景
- [ ] 3.2 实现薪资解析纯函数，用标准库 unittest 组织测试；验证：全部用例通过，`15-25K·13薪` 等折算结果符合规格
- [ ] 3.3 实现枚举归一（城市后缀去除、学历/经验档位），并补测；验证：`北京·朝阳区`→`北京`、`本科及以上`→`本科`、`3-5年`/`不限` 入档用例通过

## 4. ETL 与入库

- [ ] 4.1 实现数据集读取与必填字段校验（缺列即报错并指出列名）；验证：用缺列样例运行，错误信息符合规格场景
- [ ] 4.2 组装清洗管道（解析 + 归一 + 去重），运行并输出处理统计（总行数/重复移除/薪资缺失数）；验证：对选定数据集跑通，统计数值人工抽查合理
- [ ] 4.3 建表（`jobs`，含索引）并实现幂等覆盖式入库；验证：连续执行两遍，行数不变（幂等场景）
- [ ] 4.4 编写 ETL 使用文档（数据文件放置与运行命令）；验证：按文档从零复跑成功

## 5. 查询与分析层

- [ ] 5.1 实现数据库连接模块与筛选条件解析（城市/经验/学历 → WHERE 交集）；验证：多条件组合查询结果与手写 SQL 一致
