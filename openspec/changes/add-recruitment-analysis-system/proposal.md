# Proposal

## Why

项目需要一个真正的"招聘数据分析与可视化系统"：把招聘职位数据（公开数据集）清洗入库后，以本地 Web 仪表盘提供多维统计与图表（薪资、地域、要求、技能、公司），直观回答"市场上什么岗位、要什么技能、给多少钱"。现有 `main.py` 只是一个候选人筛选的控制台演示，不构成系统；本 change 将探索确认的整体设计系统化落地。

## What Changes

- **离线数据管道**：读取公开数据集 CSV（实施时从候选池敲定，须含薪资、城市、学历、经验、技能文本等字段），清洗后批量写入 MySQL
  - 薪资字符串解析为最低 / 最高 / 均值，覆盖 `15-25K·13薪`、`6千-1.2万`、`面议` 等常见形态
  - 城市、学历、经验枚举归一；重复记录去除
  - 入库可重复执行：重跑不产生重复数据（幂等）
- **数据库**：本机 MySQL 新建 `recruitment` 库，`jobs` 主表（utf8mb4 字符集）+ 支撑查询的索引（表结构见 design）
- **Web 仪表盘**（Flask + pyecharts，本地运行）：5 个页面——总览 / 薪资 / 地域 / 技能 / 要求·公司，约 15 张图表；页面注明数据来源与时间范围
- **筛选联动**：页面顶部常驻筛选条（城市 / 经验 / 学历），经 URL 参数传给服务端，SQL 重新聚合、图表重新渲染
- **技能分析**：jieba 分词 → 词云 + 词频柱状图；技能共现热力图
- **依赖引入**：pandas、Flask、PyMySQL、jieba、pyecharts（安装进 `.venv`，均需先向用户讲原理并获确认）
- `main.py` 原样保留，不做改动
- **明确不做**：爬虫采集、时间趋势分析、薪资预测、登录 / 权限

## Capabilities

### New Capabilities

- `data-pipeline`: 公开招聘数据集的清洗与入库——薪资解析、枚举归一、去重、幂等写入 MySQL
- `recruitment-analytics`: 招聘数据的统计与筛选口径——薪资 / 城市 / 学历 / 经验分布聚合、技能分词与共现计算
- `web-dashboard`: 本地 Flask 仪表盘——页面路由、筛选联动、pyecharts 图表渲染

### Modified Capabilities

无（项目尚无既有 specs，全部为新增能力）。

## Impact

- 代码：新增 ETL 脚本、Flask 应用、模板与图表组装代码；不改动 `main.py`
- 数据：新增 `data/` 数据集文件；本机 MySQL 新增 `recruitment` 库
- 依赖：`.venv` 新增 5 个第三方包（pandas / Flask / PyMySQL / jieba / pyecharts）
- 环境：需本机安装并运行 MySQL 服务；运行说明与启动方式在实现阶段安排
