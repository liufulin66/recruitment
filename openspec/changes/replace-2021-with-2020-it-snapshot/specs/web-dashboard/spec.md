# Spec Delta

## ADDED Requirements

### Requirement: 替换后的可用期次
系统 SHALL 在完成本次数据替换后提供 `2018` 与 `2020` 两个数据快照，不再提供已移除的 `2021` 快照；未指定期次时 MUST 展示 2020 期。访问已移除期次的旧链接时 MUST 沿用未知期次回退行为，展示实际可用的最新期次，且筛选控件与页脚保持一致。

#### Scenario: 默认展示 2020
- **WHEN** 替换已完成，用户访问未指定期次的任一分析页面
- **THEN** 页面基于 2020 期统计，期次选项包含 2018 与 2020，不包含 2021，来源说明对应 2020 公开样本

#### Scenario: 旧 2021 链接回退
- **WHEN** 替换已完成，用户访问 `snapshot=2021` 的旧链接
- **THEN** 页面正常返回并展示 2020 期，期次选中状态与来源说明不再标成 2021

#### Scenario: 保留 2018 浏览
- **WHEN** 用户切换至 2018 期
- **THEN** 仍可浏览原有 2018 期岗位与技能图表，统计不混入 2020 期记录

#### Scenario: 2020 城市选项与联动
- **WHEN** 用户查看 2020 期并选择其覆盖的城市，再通过导航切换分析页面
- **THEN** 城市选项取自 2020 期实际数据，URL 保留筛选条件；支持岗位筛选的图表按当前期次和城市统计，技能页沿用其既有筛选边界

## MODIFIED Requirements

### Requirement: 技能页图表
系统 SHALL 在技能页呈现：技能词云、词频柱状图（Top N）、技能共现热力图；技能页基于当前期次的全量技能数据呈现（不参与城市/经验/学历筛选，页面注明该限制）；当前期次无技能数据时 MUST 显示无技能数据提示，MUST NOT 呈现其他期次的技能数据。

#### Scenario: 共现热力图
- **WHEN** 打开技能页且当前期次包含技能数据
- **THEN** 热力图以 Top-N 关键词为行列，格值表示两词共现次数

#### Scenario: 当前期次无技能数据
- **WHEN** 当前期次的数据集不含技能数据，如本次接入的 2020 期
- **THEN** 技能页显示无技能数据提示，不呈现其他期次的技能图表数据

### Requirement: 数据来源标注
系统 SHALL 在每个分析页面展示当前期次的数据来源说明、数据覆盖时间范围与覆盖范围说明（从该快照的元数据读取，随期次切换变化），并注明薪资为折算口径。对于仅能确认公开时间、缺少逐条发布日期的快照，MUST 标注其公开快照时间与实际覆盖范围，不得把公开年份表述为完整的全年采集区间。

#### Scenario: 来源可见
- **WHEN** 打开任一分析页面
- **THEN** 页面可见当前期次的数据来源、覆盖时间说明与薪资口径说明

#### Scenario: 来源随期次切换
- **WHEN** 期次从 2020 切换为 2018
- **THEN** 页脚来源标注变更为 2018 期快照元数据中的来源与覆盖说明

#### Scenario: 2020 样本范围明确
- **WHEN** 当前页面展示 2020 期
- **THEN** 来源说明标注 `ccclll777/bosszp`、2020 年 4 月公开快照、12 城市 IT 岗位样本、无逐条发布日期与技能数据，不标成全国全年全量或 2024 年数据
