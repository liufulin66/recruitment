# web-dashboard Specification

## Purpose
提供本地可运行的 Web 仪表盘：把分析结果以页面与图表形式呈现，支持期次/城市/经验/学历筛选联动，并按当前期次标注数据来源与覆盖范围。

## Requirements

### Requirement: 本地服务启动
系统 SHALL 通过单条启动命令在本地启动 Web 服务，默认监听本机回环地址（端口可配置）；启动后浏览器可访问全部页面。

#### Scenario: 启动并访问
- **WHEN** 执行启动命令后访问首页
- **THEN** 服务返回 200，页面渲染总览内容

### Requirement: 页面结构
系统 SHALL 提供 5 个页面：总览、薪资、地域、技能、要求·公司；页面间通过导航互相切换；任一页面在图表数据为空时 MUST 正常渲染并显示空态提示，不得返回错误页。

#### Scenario: 正常渲染
- **WHEN** 依次访问 5 个页面
- **THEN** 每页均成功渲染，无错误页

#### Scenario: 空数据容错
- **WHEN** 当前筛选条件下某图表无数据
- **THEN** 页面显示空态提示而非报错

### Requirement: 筛选联动
系统 SHALL 在页面顶部提供期次、城市、经验、学历筛选控件；期次未选择时默认最新一期；提交后筛选条件写入 URL 参数，服务端据此重新计算并渲染该页全部指标与图表；城市筛选的可选项 MUST 随当前期次的数据取值变化；页面间导航 MUST 保留当前筛选条件（技能页的数据边界见 `recruitment-analytics` 的"技能数据的来源与筛选边界"）。

#### Scenario: 筛选生效
- **WHEN** 选择 城市=杭州 并提交
- **THEN** URL 携带对应参数，页面全部图表仅呈现当前期次的杭州岗位数据

#### Scenario: 期次切换
- **WHEN** 将期次从 2021 切换为 2018 并提交
- **THEN** URL 携带期次参数，全部指标与图表重新按 2018 期计算

#### Scenario: 筛选选项随期次变化
- **WHEN** 当前期次的城市取值集合与另一期不同
- **THEN** 城市筛选控件只列出当前期次存在的城市

#### Scenario: 导航保留筛选
- **WHEN** 带筛选条件从薪资页切换到技能页
- **THEN** URL 参数保持不变；技能页图表基于当前期次的全量技能数据呈现，并注明不支持该维度筛选

### Requirement: 总览页
系统 SHALL 在总览页呈现指标卡（职位总数、平均薪资、职位最多的城市、最高频技能）与至少两张代表图表，取值受当前筛选条件约束。

#### Scenario: 指标卡
- **WHEN** 打开总览页且带有筛选条件
- **THEN** 指标卡数值与该筛选条件下的一致

### Requirement: 薪资页图表
系统 SHALL 在薪资页呈现：薪资分布直方图、薪资箱线图、按城市/经验/学历分组的平均薪资对比图，全部响应筛选条件。

#### Scenario: 分组对比
- **WHEN** 按学历查看平均薪资对比
- **THEN** 图表展示各学历档位的平均薪资，且样本口径与薪资统计口径一致

### Requirement: 地域页图表
系统 SHALL 在地域页呈现：城市职位数量排行柱状图（Top N）与中国地图热力图（按省份汇总的职位数量着色），全部响应筛选条件。

#### Scenario: 地图热力
- **WHEN** 打开地域页
- **THEN** 地图将各城市职位数按省份汇总后着色，颜色深浅与数量成正比

### Requirement: 技能页图表
系统 SHALL 在技能页呈现：技能词云、词频柱状图（Top N）、技能共现热力图；技能页基于当前期次的全量技能数据呈现（不参与城市/经验/学历筛选，页面注明该限制）；当前期次无技能数据时 MUST 显示无技能数据提示，MUST NOT 呈现其他期次的技能数据。

#### Scenario: 共现热力图
- **WHEN** 打开技能页且当前期次包含技能数据
- **THEN** 热力图以 Top-N 关键词为行列，格值表示两词共现次数

#### Scenario: 当前期次无技能数据
- **WHEN** 当前期次的数据集不含技能数据（如 2021 期）
- **THEN** 技能页显示无技能数据提示，不呈现其他期次的技能图表数据

### Requirement: 要求·公司页图表
系统 SHALL 在"要求·公司"页呈现：学历占比环图、经验占比环图；当数据集包含公司规模/行业字段时，额外呈现对应分布图，字段缺失时 MUST 显示"数据不包含该维度"提示而非报错。

#### Scenario: 基础分布
- **WHEN** 打开要求·公司页
- **THEN** 学历、经验占比环图与当前筛选一致

#### Scenario: 字段缺失降级
- **WHEN** 数据集不包含行业字段
- **THEN** 对应图表位置显示"数据不包含该维度"提示

### Requirement: 数据来源标注
系统 SHALL 在每个页面展示当前期次的数据来源说明、数据覆盖时间范围与覆盖范围说明（从该快照的元数据读取，随期次切换变化），并注明薪资为折算口径。

#### Scenario: 来源可见
- **WHEN** 打开任一页面
- **THEN** 页面可见当前期次的数据来源、覆盖时间范围与薪资口径说明

#### Scenario: 来源随期次切换
- **WHEN** 期次从 2021 切换为 2018
- **THEN** 页脚来源标注变更为 2018 期快照元数据中的来源与覆盖说明
