# 运行说明（Web 仪表盘）

## 前置条件

1. MySQL 服务已启动，`recruitment` 库已建（见 `data/README.md`）
2. 已配置 `.env`（数据库口令，模板见 `.env.example`）
3. 已依次运行 2018、2020 的 ETL（见 `docs/etl.md`）；已有 2018/2021 的库先备份旧快照，再只运行 2020 完成原子替换
4. 依赖已安装：`.venv\Scripts\python.exe -m pip install -r requirements.txt`

## 初始化应用表（首次运行或升级后）

```powershell
.venv\Scripts\python.exe -m app init-db
```

显式创建 users、captcha_challenges 与分析表，使用 CREATE TABLE IF NOT EXISTS，不清空数据。导入应用模块不再建表。旧单快照表结构的迁移仍参考 docs/etl.md。

## 启动

```bash
.venv\Scripts\python.exe -m app
```

- 默认监听 `http://127.0.0.1:5000/`（端口可在 `config.py` 的 `WEB` 里修改）
- 默认关闭调试模式；开发时可先在 PowerShell 设置 `$env:RECRUIT_DEBUG = "1"` 开启自动重载；`Ctrl+C` 停止

## 页面导览

| 路由 | 页面 | 内容 |
| --- | --- | --- |
| `/` | 总览 | 指标卡（职位数 / 均薪 / Top 城市 / Top 技能）+ 代表图表 |
| `/salary` | 薪资 | 分布直方图、箱线图、按城市 / 经验 / 学历的平均薪资对比 |
| `/geo` | 地域 | 城市排行柱状图 + 中国地图热力图 |
| `/skills` | 技能 | 词云、词频 Top30、共现热力图（当前期次全量口径，不参与城市/经验/学历筛选；无技能数据的期次显示降级提示） |
| `/company` | 要求·公司 | 学历 / 经验占比环图（公司规模、行业：数据不包含） |

- 顶部筛选条（期次 / 城市 / 经验 / 学历）作用于除技能页外的图表；筛选条件写入 URL，可刷新、可收藏、跨页保持
- 可用期次为 2018/2020，默认最新登记的 2020；切换后全部统计与页脚标注随之变化，城市选项也随期次取值。旧 `snapshot=2021` 链接回退到 2020，控件和页脚显示实际期次
- 页脚按当前期次动态标注数据来源、覆盖时间范围与数据说明
- 2020 为 2020 年 4 月公开的 12 城市 IT 岗位样本，24,841 条，无逐条发布日期和技能明细；技能页显示“本期数据不含技能信息”，切换至 2018 仍有原技能图表。公司规模和行业维度继续显示数据不包含，不拆解混合公司标签

## 账号（首次使用）

第一次使用没有账号：访问任意页面会被带到登录页，点"去注册"注册本地账号（用户名 + 至少 6 位密码），注册成功即自动登录。

- 登录页勾选"记住我"：7 天内免登录；不勾选则关闭浏览器后需重新登录
- 页面右上角"退出"可登出
- 账号保存在 `recruitment` 库的 `users` 表（密码只存加盐哈希，不存明文）；表由 `python -m app init-db` 显式创建
- 会话签名密钥 `RECRUIT_SECRET_KEY` 在 `.env` 里（不配置也能跑：会自动随机生成，重启后旧登录失效）

验证码答案保存在 MySQL 中，5 分钟内有效，刷新撤销旧码，每次提交无论对错都会消费。Cookie 仅保存随机标识。

架构与连接生命周期见 [architecture.md](architecture.md)，隔离测试库见 [testing.md](testing.md)。

## 常见问题

- 端口被占：修改 `config.py` 中 `WEB["port"]`
- 图表空白：确认 `static/assets/` 下三个 JS 文件存在（echarts 主库 / 词云扩展 / 中国地图）
