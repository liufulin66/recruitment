# 真实样例值（解析与归一的用例输入）

## 2020 年 4 月公开样本

来源与固定版本见 `data/README.md`。CSV 原始 28,162 条，经现有岗位名/公司/城市业务键去重后 24,841 条，移除 3,321 条；薪资均可解析，无技能明细。

- 数值月薪：`job_low_salary=8000`、`job_high_salary=13000` → `8000元-13000元` → 最低 8000、最高 13000、中点 10500 元/月。源 `job_ave_salary` 不作为权威值，不补造 13 薪。
- 原始学历：本科 18440、大专 5298、硕士 2744、学历不限 1368、博士 207、缺失 105；归一后“学历不限”进入“不限”，缺失仍为空。清洗后本科 16352、大专 5025、硕士 1928、不限 1276、博士 157、缺失 103。
- 原始经验：1-3年 11578、3-5年 7660、经验不限 5668、5-10年 1511、1年以内 973、应届生 723、缺失 49；清洗后依次为 10503、6450、5066、1231、892、659、40。非空枚举无异常。
- 城市为 12 个纯城市名，省份映射全部覆盖；`job_type` 的 10 个搜索类别只保留搜索上下文，不能冒充技能。公司混合标签不解析。
- 缺一端、NaN、无穷、负数及倒置区间在真实文件未出现，用构造样例验证整组薪资缺失且岗位仍保留。

## 2018 暂存表样例

> 来源：`recruitment` 库暂存表 `job_data`（46,353 行）与 `key_map`（60,033 行），2018 年 BOSS直聘爬取。
> 用途：第 3 组"薪资解析与枚举归一"的用例输入依据。**规格中要求支持、但真实数据未出现的形态（构造用例）单独标注。**

## 薪资（salary）

- **全部 46,353 行均为小写 k 区间形态** `Xk-Yk`（正则 `^[0-9]+k-[0-9]+k$` 覆盖率 100%；无面议 / 年薪 / 13薪等形态）
- 共 251 个不同取值。高频样例：`5k-10k`(2857)、`4k-8k`(2725)、`10k-20k`(2523)、`6k-12k`(2503)、`6k-10k`(2227)、`8k-15k`(2179)、`15k-25k`(939)、`20k-40k`(419)
- 用例覆盖策略：
  - 真实形态 → `15k-25k` 等（解析器必须支持小写 k）
  - 规格要求但数据未出现的形态 → 构造用例：`15-25K`、`6千-1.2万`、`20-30万/年`、`15-25K·13薪`、`面议`、空值

## 经验（experience）

- 41 个不同取值，格式 = 前导空格 + 经验段 + 学历段 拼接，例如：
  - ` 1-3年本科`(9510)、` 3-5年本科`(9353)、` 1-3年大专`(7690)、` 3-5年大专`(4874)、` 5-10年本科`(2190)、` 不限本科`(2171)、` 1-3年不限`(1646)、` 1年以内本科`(1499)、` 不限不限`(1453)、` 应届生本科`(508)、` 1-3年中专及以下`
- 经验段见过的取值：`1年以内` / `1-3年` / `3-5年` / `5-10年` / `不限` / `应届生`
- **归一要点**：剥离前导空格；拆分并丢弃拼接的学历段（学历以独立列 `education` 为准）

## 学历（education）

- 7 个取值：`本科`(25279) / `大专`(16035) / `不限`(4455) / `硕士`(415) / `高中`(140) / `以下`(25) / `博士`(4)
- 脏值溯源：`以下`（25 行）来自源文本"中专及以下"被截断 → 归一时并入 `高中及以下` 档（档位见 `etl/cleaning.py` 的 EDU_TIERS）

## 城市（city）

- 275 个不同取值，**全部为纯城市名**（含区/后缀的为 0 条）：北京 1500 / 南京 1500 / 苏州 1500 / 成都 1500 / 广州 1440 / 西安 1440 / 合肥 1427 / 武汉 1410 / 天津 1408 / 福州 1403 / 杭州 1380 …（长尾覆盖大量地级市）
- 归一无实际脏值，但保留 trim 与整备规则；规格场景 `北京·朝阳区`→`北京` 以构造用例覆盖

## 技能表（key_map）

- 60,033 行 = 60,033 个岗位各一份技能映射（Java 序列化 HashMap：技能词 → 计数），blob 体积 82B ~ 数百 B
- **解码参考样例（已知答案）**：`id=1`（key_word=`web`）→ 预期技能词 ≈ `{app, web, spa, angular, vue, mobile, js, react, mvc, jquery}`
- 噪声预警：技能词含拼写问题（如 `orcacle`、`kubernates`），且夹杂虚词（`without`、`prepare` 等）→ 由停用词表过滤

## 数据质量备忘

- `job_data.id` 存在重复值（清洗按业务键"职位名+公司+城市"去重，不依赖源 id）
- 职位名会混入技术词，如 `Java开发工程师（elk，kibana，springboot）`
- `key_word` 共 5 类且恰好加总全部行数：`java` 11884 / `web` 11665 / `linux` 9665 / `C%23`（即 C#）6692 / `python` 6447
